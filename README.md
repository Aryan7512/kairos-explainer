# Kairos explainer

An interactive explainer for **Kairos**: letting an AI agent do more only when the evidence says it is safe.

The site is one static page (`index.html`) with three tabs: a plain-language explainer, live demos, and a technical walkthrough. There is no build step.

## The paper

The research paper goes in [`paper/`](paper/) as `paper/kairos.pdf`. When that file is deployed, the website's "Read the full paper" section shows it automatically.

## Run locally

Open `index.html` in a browser, or run `npx serve .` from this folder.

## Deploy

Deployed on Vercel as a static site (no framework, no build command, output is the repo root).
